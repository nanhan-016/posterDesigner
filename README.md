# posterDesigner

基于文化海报案例库的海报设计 skill，支持两轮标签匹配、素材用途预览和分层编辑。

入口：[poster-case-studio/SKILL.md](poster-case-studio/SKILL.md)。

## 工作流程

1. 根据用户图片和文字，使用已有标签确定活动类型、受众群体与包含内容；缺少文字时先获得自主拟写授权。
2. 按活动类型与受众群体匹配最多 40 条案例，统计风格大类，仅推荐前三名中至少出现 9 条的类别。
3. 分析并提取明显主体，展示规律平铺、主体构图、模糊背景的低分辨率预览，等待用户确认用途。没有图片时以主标题为核心。
4. 按包含内容与确认后的主视觉侧重类型匹配最多 60 条案例，统计构图，仅推荐前三名中至少出现 9 条的类别，再映射到具体模板。
5. 确认配色、初始排版与标题形式，生成独立图层，交付离线 HTML 编辑器及检查后的 PNG。

保留原案例标签库、六个风格大类、18 个视觉小类、18 张本地风格参考图、21 条实现配方与 16 个排版模板。案例的构图统计不代表模板 ID 的独立频数。

## 使用

将 `poster-case-studio` 文件夹作为 skill 使用，按其 `SKILL.md` 执行。图像生成和语义审核由智能体及其可用工具完成；离线编辑器不自行调用模型。素材预览脚本需要 Python 与 Pillow，推荐脚本需要 Node.js。

推荐算法检查：

```bash
node poster-case-studio/scripts/test_recommendations.mjs
```
