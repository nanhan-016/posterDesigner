# 主体提取与分层

## 第一阶段：分析与原样提取

在输入审核后查看实际源图。明显物体且主体感强时提取并保存透明 PNG，用它制作素材用途预览。提取应保留姿态、比例、颜色、身份、纹样和细节，不先执行最终风格化。透明背景不得包含棋盘格、实体底色或文字。

按本 skill 的用户授权，明确目标可直接处理；记录来源与准确提取对象清单，目标不明才问。不要把全部场景当作可提取物体，不能从抽象背景凭空生成主体。subjectRoster.confirmed 表示已核对提取对象的执行名单；如用户未逐项确认，私有记录需写明依据是本流程授权与实际图像判断，不伪造回复。

检查透明度、轮廓、细部、边缘光晕、主体遗漏与数量，每个缺陷最多一次自动针对性修正，仍有问题则披露。导入图片与预览脚本不会自动分割。

## 第二阶段：用户选用途后

- tile：确定间距、顺序及规律，平铺烘焙进完整底图，subjectType 为无主体；保留提取源文件但不重复导入为前景。
- blur：使用用户选择的原图或提取版本模糊为底图，subjectType 为无主体；不要再叠同一对象的清晰主体层。
- subject：不同主体数为 1 时单主体，超过 1 时多主体。统计的是物体／人物，不是文件或图层数量。默认独立主体层；用户明确要求成组时说明哪些成员一起移动，合组不把多主体标签改为单主体。

风格、配色和布局确认后，才依相应配方处理最终透明主体。生成背景时排除已提取主体、轮廓和重复碎片。Y2K 轮廓可随主体，爆炸贴纸和纹理通常在底图；Gathered Scenes 可把照片碎片及撕边作主体层；Mono-color 保留油墨处理与透明镂空。检查最终组合与原主体一致，避免同时存在背景副本与前景副本。

## 工程结构

仅主要构图元素模式使用 `subjectTreatment:"cutout"` 和重复 `--subject-image`；tile/blur/title 使用 `subjectTreatment:"background"`，不添加重复前景。最大 8 个独立层，更多主体需明确分组或扩展，不自动删素材。保留的不同主体数应在 materialUse 中记录；大于 8 的分组方案需扩展该字段当前上限并复核工具，不能假称已支持。

subjectRects 以 750×1000 参考坐标记录初始矩形。主体依原比例 contain 适配，置于背景上、文字下。稳定层 ID subject-1 至 subject-8，手动几何在 edits 保存；换模板保留主体几何与删除状态，换画布按比例映射并支持撤销。

合成海报 PNG 包含主体层；纯底图 PNG 排除独立主体层但 tile／blur 素材已在底图中，仍会保留。项目 JSON 保留原文字、资产与 materialUse。不要把已烘焙主体的背景和同主体透明 PNG 同时导入而制造重复。
